### Understanding Jupyter

I learnt that Jupyter is not a programming language. It is a system that allows me to write and run Python code in notebook form.

Jupyter Notebook is the classic interface for working with notebooks.

JupyterLab is the more modern workspace version. It allows me to open notebooks, files, terminals, and other tools in one place.

I also learnt that Jupyter notebooks are saved with the `.ipynb` file extension, which means **Interactive Python Notebook**.
